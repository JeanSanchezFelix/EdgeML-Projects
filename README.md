# Repository Overview

This repository contains example notebooks and homeworks demonstrating various techniques in model optimization, such as knowledge distillation, model pruning, quantization, and low-rank approximation. Below is a breakdown of the included files and directories.

## Directory Structure

```
├── Example Notebooks
│   ├── Knowledge Distillation
│   ├── Low Rank Approximation
│   ├── Model Pruning
│   └── Model Quantization
├── Pruning Homework
│   └── Pruning Homework.ipynb
├── Quantization Homework
│   └── input.py
├── LICENSE
└── README.md
```

## Contents

### 1. Example Notebooks
This folder includes Jupyter notebooks that provide detailed examples and explanations of key optimization techniques:

- **[Knowledge Distillation](https://nbviewer.org/github/JeanSanchezFelix/EdgeML-Projects/blob/main/Example%20Notebooks/Knowledge%20Distillation/CIIC5995_Knowledge_Distillation_Example.ipynb)**: Learn how to transfer knowledge from a larger teacher model to a smaller student model.
- **[Low Rank Approximation](https://nbviewer.org/github/JeanSanchezFelix/EdgeML-Projects/blob/main/Example%20Notebooks/Low%20Rank%20Aproximation/CIIC_5995_Low_Rank_Approximation_Example.ipynb)**: Explore techniques for reducing the rank of model weight matrices to save memory and computation.
- **[Model Pruning](https://nbviewer.org/github/JeanSanchezFelix/EdgeML-Projects/blob/main/Example%20Notebooks/Model%20Pruning/CIIC5995_Pruning_Example.ipynb)**: Understand strategies to remove unnecessary parameters from a model to improve efficiency.
- **[Model Quantization](https://nbviewer.org/github/JeanSanchezFelix/EdgeML-Projects/blob/main/Example%20Notebooks/Model%20Quantization/CIIC5995_Quantization_Example.ipynb)**: Discover methods to reduce model size and increase inference speed by lowering numerical precision.

### 2. Pruning Homework
- **[Pruning Homework.ipynb](https://nbviewer.org/github/JeanSanchezFelix/EdgeML-Projects/blob/main/Pruning%20Homework/Prunign%20Homework.ipynb)**: A hands-on Jupyter notebook exercise focused on implementing and understanding model pruning.

### 3. Quantization Homework
- **[input.py](https://github.com/JeanSanchezFelix/EdgeML-Projects/blob/main/Quantization%20Homework/input.py)**: A Python script designed to accompany the quantization homework, serving as a starting point for further experimentation.
